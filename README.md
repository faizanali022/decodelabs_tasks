# DecodeLabs Full Stack Development Tasks

This repository contains two internship submissions completed for the DecodeLabs Full Stack Development Internship (Batch 2026):

- **Task 1:** Frontend responsive homepage
- **Task 2:** Backend web application and API

## Repository Structure

```text
decodelabs_tasks/
├── project-1-frontend/   # Task 1: Responsive frontend homepage
├── task-2-backend/       # Task 2: Node.js/Express backend
└── README.md             # Root project overview
```

## Tasks Overview

### Task 1 — Lux Eco Shades Frontend
A responsive, mobile-first homepage built with semantic HTML, modern CSS, and vanilla JavaScript.

- Path: `/project-1-frontend`
- Documentation: [`project-1-frontend/README.md`](./project-1-frontend/README.md)

### Task 2 — Al Noor Maid Services Backend
A Node.js + Express + MySQL backend using MVC architecture, server-rendered views, authentication, and content management features.

- Path: `/task-2-backend`
- Documentation: [`task-2-backend/README.md`](./task-2-backend/README.md)
