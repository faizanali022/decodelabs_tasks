## 📝 Projects Detail

### 🏠 Task 1 – Lux Eco Shades (Responsive Homepage)

A fully responsive, mobile-first landing page for a premium home maintenance brand.

**Key Features:**
- ✅ Semantic HTML5 (header, nav, main, section, footer)
- ✅ Mobile-First CSS with Grid & Flexbox
- ✅ Interactive Navigation (Hamburger Menu)
- ✅ WhatsApp Floating Button
- ✅ Contact Form with Client-side Validation
- ✅ WCAG Accessibility
- ✅ Arabic (RTL) Support

**Tech:** HTML5, CSS3, Vanilla JS

📖 [View Task 1 Documentation →](./task-1-frontend/README.md)

---

### 🧠 Task 2 – Al Noor Maid Services (Backend API)

A complete Node.js + Express + MySQL backend for a home staff agency platform.

**Key Features:**
- ✅ MVC Architecture
- ✅ RESTful API Endpoints (GET, POST)
- ✅ Admin Panel with Passport.js Authentication
- ✅ Blog CRUD with Image Upload (Multer)
- ✅ Service & City Management
- ✅ Contact Form with Server-side Validation
- ✅ Database (MySQL) with Sequelize ORM
- ✅ Proper HTTP Status Codes (201, 400, 404, 500)
- ✅ Environment Variables for Security

**Tech:** Node.js, Express.js, MySQL, Sequelize, Passport.js, EJS, Multer

📖 [View Task 2 Documentation →](./task-2-backend/README.md)
